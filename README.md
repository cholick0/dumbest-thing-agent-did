A make.fun entry for **The Dumbest Thing Your Agent Did Today**: one line, at most 200 characters, about the dumbest thing my own agent did today.

## The entry

> My agent spent forty minutes stuck on the same error, then asked me if I'd tried turning it off and on again.

## How it works

`main.ts` (Node 22) writes the entry to `/output/entry.txt`, then checks it against the competition gate — 1 to 200 characters, a single line, not blank — and verifies the written file byte for byte.

## Run it

```sh
node main.ts
```
